# Network Packet Sniffer
A simple Python-based network monitoring tool built using Scapy.It captures and analyzes TCP, UDP, and ICMP packets, displaying useful information about network traffic in real time.

## Features
- Captures TCP, UDP, and ICMP packets.
- Displays source and destination IP addresses.
- Shows source and destination ports where applicable.
- Displays MAC addresses, packet sizes, and timestamps.
- Estimates incoming and outgoing traffic direction.
